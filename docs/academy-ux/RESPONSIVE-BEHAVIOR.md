# Comportamiento responsive de Watchmaking Academy

## Escritorio amplio: 1260 px o más

- navegación persistente;
- contenido principal;
- panel contextual solo cuando aporta valor;
- lector dividido y workspace con relación ajustable;
- laboratorios en una zona propia bajo el viewport.

## Escritorio estrecho: 900–1259 px

- navegación compacta;
- panel contextual como drawer;
- tarjetas a una columna;
- workspace con panel de pasos y escenario; contexto en pestañas inferiores.

## Ventana estrecha: menos de 900 px

- navegación primaria resumida y menú de más opciones;
- cabeceras y acciones apiladas;
- lector en un modo a la vez;
- viewport con altura mínima estable;
- taller y paneles debajo del 3D;
- tablas convertidas en tarjetas o con scroll explícitamente anunciado.

## Touch

- controles de 44 px;
- no hover-only;
- filtros como panel plegable;
- ratios de workspace mediante presets, no arrastre obligatorio.

## Texto ampliado

- no se bloquea la altura total;
- las áreas principales pueden desplazarse;
- IDs y hashes se parten sin desbordar;
- las acciones conservan texto o nombre accesible.
