# Flujos de usuario de Watchmaking Academy

## Primer acceso

1. Entrar en Academia desde el conmutador de contexto.
2. Si el perfil no tiene actividad previa, abrir onboarding.
3. Declarar experiencia previa, objetivos y duración preferida.
4. Guardar preferencias localmente.
5. Recibir una recomendación derivada del catálogo real.
6. Abrir ruta, módulo o lección sin crear sesión todavía.

## Continuar aprendizaje

1. Inicio prioriza una sesión recuperable si existe.
2. En ausencia de bloqueo, presenta la recomendación explicable real.
3. Mi aprendizaje muestra ruta activa, última actividad, competencias en curso y próximas prácticas.
4. Preparar actividad ejecuta preflight.
5. Solo “Crear sesión e iniciar” persiste un intento nuevo.

## Estudiar una lección

1. Abrir ruta.
2. Seleccionar módulo y lección.
3. Elegir modo lectura, visual, dividido, foco o textual.
4. Consultar glosario, fuentes y cuaderno sin perder contexto.
5. Abrir una actividad vinculada.
6. Guardar/salir o completar; el estado técnico se restaura.

## Practicar en Taller

1. Filtrar por banco, calibre, subsistema, nivel o tipo.
2. Abrir una actividad existente; no se duplica contenido.
3. Usar controles semánticos, teclado o puntero.
4. Guardar checkpoint y reanudar.
5. Consultar evidencia y resultado.

## Consultar Atlas

1. Elegir fixture conceptual o calibre real.
2. Filtrar piezas por subsistema, estado R, G/K/P o fuente.
3. Abrir una pieza/instancia.
4. Revisar identidad, procedencia, geometría, relaciones y limitaciones.
5. Saltar a actividades relacionadas cuando existan.

## Revisar y retener

1. La cola agrupa competencias practicando, demostradas y retenidas.
2. Cada tarjeta explica por qué aparece.
3. Una recomendación de retención nunca altera mastery por sí sola.
4. Solo una actividad posterior produce nueva evidencia evaluable.

## Buscar y tomar notas

1. Buscar en currículo, actividades, fixtures, piezas, glosario, fuentes y notas.
2. Filtrar por tipo.
3. Abrir el deep link exacto.
4. Crear una nota contextual privada.
5. Exportar notas explícitamente; nunca se envían ni se incluyen en paquetes.
