# Watch Prototype Lab 0.9.0

## Academia

- Tres rutas nuevas: fabricación y acabados, diseño de reloj propio y validación.
- 18 módulos, 18 lecciones, 18 prácticas y 15.221 palabras de teoría nueva.
- Procesos para caja, esfera, agujas, platinas, puentes, micromecánica y decoración.
- Progresión de diseño: movimiento adquirido, modificación controlada y movimiento propio.
- Protocolos de revisión relojera, principiantes, transferencia, accesibilidad y retención a 1/7/21 días.
- Workspaces documentales específicos, tutor contextual acotado y revisión humana obligatoria.
- Total integrado: 7 paquetes relojeros, 11 rutas, 85 módulos, 104 conceptos y 157 prácticas.

## Límites preservados

- Una planificación digital no declara fabricada una pieza.
- Una puerta de diseño no modifica el proyecto técnico ni declara fabricabilidad.
- Una respuesta digital no acredita destreza manual.
- Un hallazgo crítico bloquea la liberación y requiere revisión humana.
- El libro privado se usa como teoría complementaria y no como documentación MIYOTA.

## Instalación

El instalador Windows x64 incluye la aplicación de escritorio, la Academia offline y el motor CAD. Se genera con manifiesto y SHA-256. Mientras no exista una firma Authenticode comercial, Windows puede mostrar “Editor desconocido”.
